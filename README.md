## Folder/ Directory Structure

- `.devcontainer` - Microsoft Devcontainer config
- `.github` - GitHub config
- `.idea` - CLion config
- `.pio` - Platformio stuff
  - `build` - Platformio build directory
  - `libdeps` - Platformio libraries
- `.PVS-Studio` - PVS Studio stuff
- `.vscode` - VSCode config
- `boards` - Custom board definitions
- `demos` - Nacelle specific demos, Arduino compatible for ease of use
  - `ActuatorDemo` - Manually control the actuator
  - `CommunicationDemos` - Comms demo and MAC Address getter
  - `EncoderDemo`
  - `NacelleDemo` - Manually control the actuator
- `docs` - documentation
  - `config` - Doxygen config
  - `cpp` - Notes on C++
  - `doxygen-out` - Autogenerated Doxygen API dos
  - Miscellaneous Windows Scripts/ batch files (`.bat`)
- `include` - Miscellaneous header files
  - `Encoder.hpp`
  - `NacelleConfig.hpp` - Nacelle specific configuration
  - `NacelleContainer.hpp` - Hold shared variables
  - `NacelleFSM` - Finite state machine implementation for the nacelle
  - `NacelleTasks.hpp` - FreeRTOS task function declarations and related datatypes
- `lib` - Private libraries
  - `2026-Controls-Core` - Common files - [`CalPolyWindPower/2026-Controls_Core`](https://github.com/CalPolyWindPower/2026-Controls_Core)
- `logs` - Log files from the serial console / monitor
- `src` - Miscellaneous source files
- `test` - Where tests would go if he had them
- `platformio.ini` - Platformio config
- MISRA - Rules for automotive code quality
